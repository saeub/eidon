# Experiment types

| Experiment type | Description |
| --- | --- |
| [`ClassAnnotation`](ClassAnnotation) | Annotation experiment for text classification, where participants select a label for each text, optionally with multiple-choice questions shown after. |
| [`MultiPageReading`](MultiPageReading) | Reading experiment with longer, multi-page text stimuli, optionally with multiple-choice questions shown after the text. |
| [`SinglePageReading`](SinglePageReading) | Reading experiment with short, single-page text stimuli, optionally with multiple-choice questions shown after the text. |
