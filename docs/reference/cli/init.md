# CLI command: `eidon init`

Set up a new experiment directory with a minimal configuration file and materials folder.

## Usage

```
eidon init [-h] [--experiment EXPERIMENT]
                        {ClassAnnotation,MultiPageReading,SinglePageReading}

Set up a new experiment directory with a minimal configuration file and
materials folder.

positional arguments:
  {ClassAnnotation,MultiPageReading,SinglePageReading}
                        Type of the experiment to create.

options:
  -h, --help            show this help message and exit
  --experiment, -e EXPERIMENT
                        Path to the new experiment directory.
```
